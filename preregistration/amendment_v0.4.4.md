# Поправка v0.4.4 к пре-регистрации Norm Provenance Ledger v0.4

Дата: 2026-09-30. Вносится после расширенной проверки надёжности (reliability_rel30_v0.4.3.md) и до полной разметки.

1. Полная разметка подтверждающего набора (54 A + 47 B, за вычетом технических исключений) выполняется обоими судьями (J1 terra, J2 sol) на всех трассах. Отказ судьи – один повторный запуск; при повторном отказе трасса исключается для этого судьи и считается.
2. Основные оценки H1, H2, H5 сообщаются отдельно по каждому судье и по согласованному набору (события, которые оба судьи отметили в одном блоке для нормы того же типа). Вывод считается устойчивым, только если направление эффекта совпадает у обоих судей.
3. H3 и сравнение числа собственных правил агента между корпусами сообщаются как описательные: межсудейное согласие по этой категории на расширенной проверке ниже порога (Спирмен 0.38; κ по unsupported −0.06).
4. H4 по FM-1.2: если ни один судья не отметит нарушений норм role в подтверждающем наборе B, сопоставление с FM-1.2 сообщается как непроверяемое на этой рубрике; наблюдение о противоречащих записи внешних ограничениях в ChatDev (отказ от GUI вопреки спецификации) сообщается описательно, без пересчёта в нарушения role.
5. 30 трасс расширенной проверки входят в полную разметку; их результаты J1 и J2 используются как есть, без повторного запуска.
